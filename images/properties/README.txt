CANYON CREEK — PROPERTY & BUSINESS PHOTOS
==========================================

Drop your in-game screenshots in this folder to have them show up on the
Land & Business Office page.

HOW IT WORKS
------------
1. Take a screenshot in-game of the ranch, home, or business.
2. Save/copy the image file into this folder (images/properties/).
   Keep file names simple, no spaces — e.g. silver-bend-ranch.jpg
3. Open admin.html on the site, sign in, edit the matching listing, and
   type that exact file name into the "Image File Name" field, then save.
4. The photo will automatically appear on that listing's card on
   properties.html, and in its deed popup.

NOTES
-----
- Supported formats: .jpg, .jpeg, .png, .webp
- Recommended size: roughly 800x500px (or similar wide/landscape shape)
  keeps things looking sharp without a huge file size.
- If a listing has no image file name set (or the file isn't found),
  the site automatically falls back to its colored placeholder scene —
  nothing breaks if you haven't added a photo yet.
- You can rename or replace a photo at any time — just make sure the
  file name in this folder matches the file name saved on the listing
  in admin.html.

TEST IMAGES ALREADY IN THIS FOLDER
-----------------------------------
Every listing currently points at a generated placeholder photo (stamped
"TEST IMAGE" in the corner) so you can see how real screenshots will look
on the site before you've taken any. When you're ready, just take your
in-game screenshot, save it over the matching file (or a new name — update
admin.html either way), and the test photo is gone for good.
